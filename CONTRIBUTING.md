# Contributing

Thank you for taking the time to improve Python Data Quality Checker.

## Development setup

1. Install Python 3.8 or newer.
2. Clone the repository.
3. Open a terminal in the project directory.

This project uses only the Python standard library, so no package installation is required.

## Run the tests

```bash
python -m unittest discover -s tests -v
```

## Before submitting a change

- Keep changes focused and explain their purpose.
- Add or update unit tests for behavior changes.
- Run the full test suite.
- Update the README when commands, options, or behavior change.
- Do not include real customer data, credentials, or other sensitive information in sample files.

## Pull requests

Describe the problem, summarize the solution, and include the test command and its result. Keep pull requests small enough to review easily.
