# Security Policy

## Supported versions

Security fixes are intended for the latest version on the default branch.

## Reporting a vulnerability

Please do not publish passwords, API keys, private customer data, or exploit details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository owner privately through their GitHub profile.

This project is a learning project and is not intended to process confidential or regulated data without an independent security review.
